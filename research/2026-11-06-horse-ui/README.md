# v2.4 马匹战绩与加载状态

2026-11-06，用户反馈 v2.3 近五场战绩窄列换行、空白过大，以及详情加载提示不明显。本轮保留现有月历和赛事地区主题，修改真实详情的战绩卡、资料补全与加载表现。开发包 `dist/GⅠ 赛马日历 Dev v2.4.app`，0.2.4 / build 6。

## 战绩卡

根因是实际战绩按钮只有一个文本节点，却套用了原型为「等级图标／名称／箭头」设计的三列网格。文本占据第一列约 42px，形成截图里的日期、场次和等级逐行堆叠。现在使用明确的日期、名称、场地／距离／骑师、成绩四个区域。

- 冠军金色，2—5 名蓝色，其他名次紫灰色。整条背景从左向右渐淡，名次本身保持醒目。
- 日期独立显示；赛事名占主要宽度，G1／G2／G3 使用现有等级图标；Jpn 等级保留真实文字标记。
- 显示赛场、已取得的距离与骑师。右侧优先显示完赛时间，其次着差，再其次最终单胜；有时间／着差和赔率时，赔率作为次级信息保留。
- 香港马匹档案本身不提供全部赛事名称，按需补查该场结果，核对日期、场次、马匹身份，保存于原有 SQLite 详情缓存。一次最多两个请求，已有名称的缓存不重新联网。保留本场之前的五场，不引入未来战绩。
- 日本地方出马表中的赛前记录补取赛场、距离、骑师和完赛时间。按每行末尾的历史列对齐，避免 rowspan 导致骑师／时间错位。新字段从已取得的官方 HTML 解析；未取得的不猜测。
- 来源的「--」不当作完赛时间。香港 `2.26.92` 与日本 `1:22.9` 统一为含冒号的时间显示。历史冠军已有的胜出着差保留，避免被赛果表的占位横线覆盖。

## 爱丽速子状态

使用内置 image_gen 新生成的透明 2×2 Q 版贴图，配合 CSS 两帧奔跑、举手跳跃和叉腰待机。素材位于 `design/assets/agnes-tachyon-status-sprites-v1.png`，完整提示词与角色来源见[素材记录](../../design/assets/agnes-tachyon-status-prompt-85.md)。没有增加 3D 引擎或运行时依赖。

- 真正需要获取详情或近五场补查时奔跑，气泡说明正在加载。
- 新资料取得后举手跳跃并显示「加载完成」，约 3.2 秒后叉腰待机。
- 本地资料可用时先显示资料并直接叉腰，后台检查不遮挡旧内容。历史名称缓存命中时不闪现网络加载状态。
- 来源失败、未匹配或离线缺项时说明实际情况，不播放成功动画。
- 返回、关闭或切换马匹后，旧异步响应不覆盖当前马匹。新数据回填日本地方记录时保留原滚动位置。
- 减少动态效果偏好下停止循环动画，保留状态文字与姿态。普通预览／虚构马券界面不继承真实详情的状态小人和卡片标记。
