# 第73轮：普通界面字体统一

2026-10-28。用户截图指出“继续查看新更正”同一行有不同字体，要求同类别统一，特殊标注／艺术字保留。本轮修复字体，不继续增加功能或推进 U5。

[字体修复预览](http://127.0.0.1:8765/index.html?preview=calendar&settingsMenu=preview&lang=zh&year=2026&month=10&refund=preview&notifications=preview&v=73)。沿用第72轮主月历和四种通知场景。

## 复现与原因

共用字体列表原先首选 Hiragino Sans。用 Python 标准库 ctypes 调用 macOS CoreText，按共用样式的首选字体逐字检查真实按钮文案：原来“继、续、查”选择 PingFang HK，“看、新、更、正”选择 Hiragino Sans。同一行因此发生逐字字体回退，字面大小和粗细观感不同。修复前 `python3 research/check_ui_typography.py` 已触发断言失败。

同时核对普通文字的显式 font-family／font 简写、按钮字重及其内部标签。标签是普通文字加独立箭头，箭头有专门字号；不把箭头大小与正文强行合并。主要按钮另有 850／800／750 字重差异，已按同类确认操作对齐为 800。

## 修复范围

- 共用普通文字优先 PingFang SC；中文／繁体／英文标签不再由日文字体与中文回退字体混排。Windows 中文备选优先 Microsoft YaHei。
- 日文标注采用 :lang(ja) 的 Hiragino Sans／Yu Gothic，避免只改中文优先后，日文汉字与假名又发生混排。已有 lang 属性的日本赛事、马名和日文界面继续使用日文字体。
- 输入框、下拉框和多行输入统一使用界面字体。小店、共用主要按钮、缓存删除确认统一主要操作字重，保留原有字号与信息层级。
- GⅠ 徽章、装饰编号／标志等 Georgia 字体，以及导航箭头的 Arial 规则保留；没有改变地区配色、资金逻辑或页面布局。
- 六个 HTML 共用样式引用更新至 v73，便于直接文件和网页入口刷新到同一版本。无新依赖、字体下载或系统设置修改。

## 验证与边界

`python3 research/check_ui_typography.py` 修复后通过：中文按钮、设置／缓存标签、繁体、日文及英文共九条样例，每条按语言对应的系统字体检查时均只用一个字体家族；三个主要确认按钮的样式字重相同。真实逐字字体记录保存在 `ui-typography-check-73.json`。

六个 HEAD 请求均 200／no-store，包含主月历、共用样式、小店样式、缓存样式、设置和语言选择入口。本轮没有浏览器渲染或截图比对；系统字体回退检查能证明已知混用原因被消除，最终像素观感仍由用户网页查看。没有把这次字体修复记作 U4 视觉整体通过。
