# 第82轮 日本马匹身份与历史赛事定位

## 天皇赏（秋）

在11月1日东京第11场、芝地2000米这个比赛范围内，以马号对照正式枠顺及两份正式赛果，再核对名次。17个日文名与英文名全部对应。英文赛果的三个马号附带 `B` 装备标记，比较时提取数字并保留原值。

## 本机读取结果

八次普通HTTP尝试中，JAIRS英文赛果返回200，三个JRA页面返回403，一个JRA页面及两次JBIS读取出现TLS断连，netkeiba候选页返回400。日文赛果与五个历史链接通过公开网页核对。自动读取日文档案与历史详情仍是V5的验收缺口。

[verified.json](verified.json)保留配对结果、已核验的链接和每次本机请求状态。`live/`保存本机响应及哈希。`verify.py`复用既有HTML解析，使用人工核对的JRA字段作为对照，复跑时读取本地文件。17个同场配对、五个历史实例和八份响应哈希均通过。`probe.py`保留首次五个公开入口的请求脚本，其他三个请求见本机记录。

本轮产出属于研究验证。正式应用的日文资料接入、自动历史详情读取和更正版本验证仍待完成。
